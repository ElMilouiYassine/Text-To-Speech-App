# Text-to-Speech App

## Description

L'application **Text-to-Speech** permet à l'utilisateur de convertir du texte en parole en utilisant les voix disponibles sur le navigateur. L'utilisateur peut personnaliser plusieurs paramètres tels que la voix, la vitesse de lecture, et contrôler la lecture en mettant en pause, reprenant ou arrêtant la lecture du texte. Ce projet est développé avec **React** et utilise l'API **Speech Synthesis** pour la conversion du texte en parole.

## Fonctionnalités

- **Saisie de texte** : L'utilisateur peut entrer du texte dans une zone de saisie.
- **Sélection de la voix** : L'utilisateur peut choisir parmi les voix disponibles dans le navigateur (ex. : voix arabe `ar-SA`).
- **Vitesse de lecture** : L'utilisateur peut ajuster la vitesse de la lecture du texte (de 0.5x à 2x).
- **Contrôles de lecture** :
  - Lire le texte
  - Mettre en pause
  - Reprendre la lecture
  - Arrêter la lecture
- **Affichage de la phrase en cours** : L'application affiche la phrase actuellement lue.

## Installation

1. Clonez ce repository :

   ```bash
   git clone https://github.com/votre-utilisateur/text-to-speech-app.git

   ```

2. Accédez au dossier du projet :
   cd text-to-speech-app

3. Installez les dépendances :
   npm install

4. Lancez l'application :
   npm start

# Technologies utilisées

React : Pour la gestion de l'interface utilisateur.
Speech Synthesis API : Pour la conversion du texte en parole.
Font Awesome : Pour les icônes dans le footer.
